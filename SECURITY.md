### Reporting a Vulnerability

We prioritize the safety, integrity, and security of quickOS. If you discover a security vulnerability, please follow our responsible disclosure protocol:

1. **Do not file a public GitHub issue.**
2. Send a detailed report directly to:  
   📧 **Security Team:** <security@ucdreams.com>  
   📧 **Developer Contact:** <me@uchitchakma.com>
3. Please include:
   - Operating system and version (macOS, Windows, Ubuntu, Android, iOS)
   - Steps to reproduce the issue
   - Proof-of-concept code or description of potential impact

We will acknowledge receipt within 48 hours and work with you to remediate and verify any validated security findings before public disclosure.
